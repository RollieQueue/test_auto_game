# Корни и нити

Игра о лесной грибнице в стиле тетради натуралиста. Тяни нити мицелия сквозь почву, находи воду и минералы, заключай союз с деревьями и выращивай грибы.

## Как запустить

**Windows:** дважды кликните `start.bat`. Откроется браузер с игрой по адресу `http://127.0.0.1:5173/`. Чтобы остановить игру, закройте чёрное окно сервера.

**Любая система с Node.js 18+:**

```
npm start
```

**Без Node.js** (нужен Python 3): из папки игры выполните `python -m http.server 5173` и откройте `http://127.0.0.1:5173/`.

Просто открыть `index.html` двойным кликом нельзя: браузеры не загружают модули JavaScript с `file://`.

## Управление

- Зажмите кнопку мыши на светлой нити и ведите: нить прорастёт по пути, если хватит сахара.
- `1`: инструмент «Нить», `2`: инструмент «Гриб».
- Пробел: пауза.

## Для разработки

- `npm test`: тесты генерации мира и симуляции (Node 18+, без зависимостей).
- Параметры адреса: `?seed=7` фиксирует мир, `?autostart=1` пропускает титульный экран, `?debug=1` включает отладку.
- Устройство кода описано в `docs/ARCHITECTURE.md`, дизайн игры в `docs/GDD.md`.
